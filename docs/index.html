Interactive Features

Automated ATS & Cold Recruiter Studio

Never duplicate an application again. The platform tracks your submissions and powers direct outreach from your browser.

✓ Real-time "Already Applied" Ribbons

Every job card dynamically checks your tracking sheet (Google Sheets & local database) using fuzzy company name normalization to prevent duplicate applications.

  • ✓ Auto-Mark on Portal Click: Clicking "Apply on Portal" immediately turns the card green and marks it as applied.
  • ✓ Historical Sync: Automatically links past applications (Litmus7, Urolime, Enfin, Seqato) on page load.
  • ✓ 1-Click Manual Toggle: Use "+ Mark as Applied" anytime to track external submissions from your phone.
  • ✓ Explorer Filters: Isolate applied jobs or click "Hide Applied" to view only fresh openings.
✉️ 1-Click Recruiter Cold Outreach Studio

Turn discovered vacancies into immediate interview opportunities by emailing the hiring manager directly from the job card.

  • ✓ HR Contact Discovery: Automatically scrapes recruiter names, direct emails, and phone numbers.
  • ✓ AI Personalized Pitch: Generates tailored email copy mentioning 3+ years DevOps experience, Kubernetes, and CI/CD.
  • ✓ Automated Resume Attachment: Delivers your PDF resume directly via the Gmail API without manual file browsing.
  • ✓ Dual Fallback: Provides an instant "Open in Mail App" mailto link if you prefer your desktop email client.
Deployment Manual

Step-by-Step Installation & Setup

Complete guide to running the entire stack on AWS EC2 with Docker Compose, automated SSL certificates, and n8n webhooks.

1
Provision AWS EC2 Host & Firewall
Infrastructure

Launch an Ubuntu 24.04 LTS instance (type t3.small or t3.medium). Configure your Security Group inbound rules to allow:

EC2 Security Group Ports 
Port 22   (SSH)          -> Your IP
Port 80   (HTTP)         -> 0.0.0.0/0 (Caddy ACME Challenge)
Port 443  (HTTPS)        -> 0.0.0.0/0 (Production Secure Web Traffic)
2
Clone Repository & Install Docker
Server Init

SSH into your EC2 instance and run the one-line Docker setup:

bash 
# Install Docker and Docker Compose v2
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
newgrp docker

# Clone repository
git clone https://github.com/Xopscloud/job-search-automation.git
cd job-search-automation
3
Configure Environment Variables (.env)
Configuration

Create your environment configuration file in the project root:

.env 
# Domain & Caddy SSL
DOMAIN_NAME=devopspulse.yourdomain.com
ACME_EMAIL=your-email@gmail.com

# n8n Workflow Settings
N8N_PORT=5678
N8N_HOST=devopspulse.yourdomain.com
N8N_PROTOCOL=https
WEBHOOK_URL=https://devopspulse.yourdomain.com/

# AI Matcher API Keys (Choose one or multiple)
OPENAI_API_KEY=sk-...
GROQ_API_KEY=gsk_...
GEMINI_API_KEY=AIza...

# Email & Outreach
GMAIL_USER=your-email@gmail.com
RECIPIENT_EMAIL=your-email@gmail.com
4
Start Containers via Docker Compose
Deployment

Build and start all 4 services in detached mode:

bash 
# Build and spin up containers
docker compose up -d --build

# Verify container health
docker compose ps
# caddy            Up (0.0.0.0:80, 0.0.0.0:443)
# web-app          Up (3000)
# n8n              Up (5678)
# scraper-service  Up (8000)
5
Import n8n Master Workflow
n8n Setup

Navigate to https://devopspulse.yourdomain.com in your browser. Complete n8n initial admin registration, then:

1. Go to Workflows ➔ Click Add Workflow ➔ Select Import from File.

2. Choose workflows/master_job_search_workflow.json from the repository.

3. Activate the workflow toggle in the top-right corner to start the cron schedule.
